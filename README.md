# multivariate-analysis-ireland

This project is adapated from coursework completed for STAT40150 at University College Dublin. The analysis has been extended to use the full dataset and refined to improve clarity and presentation. 

## Overview
This project applies a range of multivariate statistical and machine learning techniques to analyze socio-economic patterns in Ireland.

The analysis is based on the 2022 Pobal HP Deprivation Index dataset, derived from the 2022 Census of Population, which shows the level of overall affluence and deprivation at the level of electoral division across Ireland.

The goal of this project is to uncover underlying structure in the data and provide interpretable insights into socio-economic variation across the country.

## Methods
- Exploratory data analysis
- Data preprocessing and standardization
- Hierarchical and k-means clustering
- Classification using Linear Discriminant Analysis (LDA) and Quadratic Discriminant Analysis (QDA)
- Principal Component Analysis (PCA)
- Principal Component Regression (PCR)
